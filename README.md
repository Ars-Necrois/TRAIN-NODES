## 🇪🇸 Español

¡Bienvenido/a a **Train Nodes**! Este es un juego interactivo donde tu objetivo principal es **dibujar las vías de tren** sobre el mapa para que un tren las recorra en tiempo real, conectando estaciones y creando tu propia red de transporte.

### 🎮 Cómo se juega
- **Dibuja la ruta:** Usa el ratón o la pantalla táctil para trazar los caminos por donde circulará el tren.
- **Conecta nodos:** Diseña una red eficiente para que el tren llegue de un punto a otro sin problemas.
- **Gestiona el recorrido:** Asegúrate de que las vías estén bien conectadas para evitar accidentes y completar los trayectos.

### 🛠️ Tecnologías y Herramientas
- **Lenguajes:** JavaScript, HTML5 Canvas, CSS3
- **Entorno:** Web (funciona directamente en el navegador)

## 🇬🇧 English

Welcome to **Train Nodes**! This is an interactive game where your main goal is to **draw train tracks** on the map so a train can travel along them in real-time, connecting stations and building your own transport network.

### 🎮 How to Play
- **Draw the path:** Use your mouse or touchscreen to trace the paths the train will follow.
- **Connect nodes:** Design an efficient network so the train can travel smoothly from point to point.
- **Manage the journey:** Make sure the tracks are properly connected to avoid accidents and complete trips.

### 🛠️ Technologies & Tools
- **Languages:** JavaScript, HTML5 Canvas, CSS3
- **Environment:** Web (runs directly in the browser)
